# 🚀 加密货币数据分析演示项目

基于 OpenBB 平台和 Gate.io API 的专业加密货币数据分析工具

## 🎯 项目简介

这是一个功能完整的加密货币数据分析演示项目，专门设计用于获取、分析和可视化比特币（BTC）和以太坊（ETH）的市场数据。项目优先使用 Gate.io API 作为数据源，提供实时、准确的市场数据分析。

### 🌟 核心特性

- **🚀 Gate.io API 集成** - 优先使用 Gate.io 交易所的实时数据
- **📊 专业图表分析** - 多维度价格走势和技术指标可视化  
- **🔍 深度市场分析** - 详细的价格、成交量、波动率分析
- **🎨 中文界面** - 完全中文化的用户界面和文档
- **💾 数据导出** - 高分辨率图表保存功能
- **🔄 多数据源支持** - Gate.io API + OpenBB 备用数据源

## 🚀 快速开始

### 1. 环境要求

- **Python**: 3.9 - 3.12
- **操作系统**: Windows / macOS / Linux
- **网络**: 需要互联网连接（Gate.io API 版本）

### 2. 安装依赖

```bash
# 安装必要的 Python 包
pip install pandas matplotlib numpy requests

# 可选：安装 OpenBB 平台（备用数据源）
pip install openbb
```

### 3. 运行程序

#### 🎯 推荐方式：使用交互式启动器

```bash
python run_crypto_demo.py
```

然后根据菜单选择：
- **选项 1**: 离线版（使用模拟数据，无需网络）
- **选项 2**: Gate.io API 版（获取真实数据）
- **选项 3**: 完整版（需要更多 API 配置）

#### 🌐 直接运行 Gate.io API 版本

```bash
python crypto_demo_simple.py
```

#### 📊 运行离线演示版本

```bash
python crypto_demo_offline.py
```

## 🔧 Gate.io API 配置

### 无需 API 密钥

本项目使用 Gate.io 的**公开 API 端点**，无需注册或申请 API 密钥即可获取：
- 实时价格数据
- 历史K线数据
- 交易量信息
- 24小时统计数据

### API 限制说明

- **请求频率**: 每秒最多 10 次请求
- **数据延迟**: 实时数据（几乎无延迟）
- **历史数据**: 支持多种时间间隔（1分钟到1周）
- **数据范围**: 支持获取任意时间段的历史数据

## 📈 技术指标说明

### 移动平均线 (Moving Average)
- **MA(20)**: 20日简单移动平均线，短期趋势指标
- **MA(50)**: 50日简单移动平均线，中期趋势指标
- **金叉/死叉**: MA(20) 上穿/下穿 MA(50) 的技术信号

### 价格相关性分析
- **相关系数范围**: -1 到 +1
- **强正相关**: > 0.7，价格走势高度一致
- **中等相关**: 0.3 - 0.7，价格走势较为一致
- **弱相关**: -0.3 - 0.3，价格走势相对独立
- **负相关**: < -0.3，价格走势相反

### 波动率计算
- **年化波动率**: 基于日收益率标准差计算
- **计算公式**: σ_annual = σ_daily × √365
- **意义**: 衡量价格波动的剧烈程度

## 🔍 故障排除

### 常见问题

**Q: 程序提示"无法获取数据"**
A: 
1. 检查网络连接是否正常
2. 尝试运行离线版本：`python crypto_demo_offline.py`
3. 稍后重试，可能是临时的网络问题

**Q: 图表无法显示**
A:
1. 确保系统支持图形界面
2. 检查 matplotlib 是否正确安装
3. 图表文件仍会保存到本地目录

**Q: 数据获取速度较慢**
A:
1. 这是正常现象，API 有速率限制
2. 程序会自动控制请求频率
3. 耐心等待数据获取完成

### 依赖问题解决

```bash
# 如果遇到包导入错误，重新安装依赖
pip install --upgrade pandas matplotlib numpy requests

# 如果需要 OpenBB 备用功能
pip install openbb

# 清理并重新安装（如果遇到版本冲突）
pip uninstall pandas matplotlib numpy
pip install pandas matplotlib numpy
```
